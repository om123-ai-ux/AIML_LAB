1. GRAPH-BASED ALGORITHMS (BFS, DFS, UCS, Greedy, A*)
─────────────────────────────────────────────────────
Start Node : A
Goal  Node : G

Unweighted Graph Adjacency List:
  A : [B, C]
  B : [A, D, E]
  C : [A, F]
  D : [B]
  E : [B, G]
  F : [C, G]
  G : [E, F]

Weighted Graph (node, cost):
  A : [(B,1), (C,4)]
  B : [(A,1), (D,2), (E,5)]
  C : [(A,4), (F,3)]
  D : [(B,2), (G,8)]
  E : [(B,5), (G,2)]
  F : [(C,3), (G,6)]
  G : [(D,8), (E,2), (F,6)]

Heuristic h(n) – estimated distance to G:
  A=9, B=7, C=6, D=5, E=2, F=4, G=0

2. N-QUEENS PROBLEM (Hill Climbing, Simulated Annealing, Backtracking, Forward Checking)
─────────────────────────────────────────────────────
Board Size : 8×8  (N = 8)
Goal       : Place 8 queens such that no two queens attack each other
             (no two queens share the same row, column, or diagonal)

Board Representation:
  A list of length N where index = column, value = row of the queen
  Example: [0, 4, 7, 5, 2, 6, 1, 3]
           → Queen in col 0 is at row 0
           → Queen in col 1 is at row 4
           → ... and so on
